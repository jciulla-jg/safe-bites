# Safe Bites

A mobile-first, allergen-aware restaurant finder. Save your food restrictions
once, with how strict each one is. Then search restaurants near any zip code
and see which have menu items that are safe for you, plus an honest label on
how much to trust that data.

- **Try it:** https://jciulla-jg.github.io/safe-bites/
- **Run it yourself:** see [SETUP.md](SETUP.md).

Built with Expo (React Native + TypeScript), Supabase and OpenStreetMap, all
on free tiers. Allergen data is best-effort and not confirmed with kitchens,
so always tell staff about your allergy.
